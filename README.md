# mosud-course

Практикум по курсу МОСУД: SQL и математические модели управления данными.
Набор данных: Brazilian E-Commerce Public Dataset by Olist (CC BY-NC-SA 4.0),
СУБД: PostgreSQL 17 в Docker.

| Каталог | Работа |
|---|---|
| `lab01/` | Развёртывание PostgreSQL и загрузка Olist |
| `lab02/` | Множества и мультимножества в SQL (вариант 4: BA/PE) |
| `lab03/` | Выборка, проекция, переименование и реляционная алгебра (вариант 4: customers) |
| `lab04/` | Отзывы и опоздания, JOIN |
| `lab05/` | Кванторы и деление: GO/DF/MT |
| `lab06/` | Число заказов покупателя относительно среднего штата |
| `lab07/` | NULL и профиль качества |
| `lab08/` | ER-модель купонов |
| `lab09/` | Нормализация купонов |
| `lab10/` | Нормализация по предоставленному файлу №10 |
| `lab11/` | VIEW, MATERIALIZED VIEW и рекурсия PR |
| `lab12/` | Транзакции, блокировки и восстановление |
| `lab13/` | Составной и частичный индексы отзывов |
| `lab14/` | NOT IN, NOT EXISTS и анализ планов |

## Быстрый запуск

1. Поднять базу: `docker compose up -d` в каталоге `lab01` (хост-порт 5433).
2. Применить `lab01/schema.sql`, загрузить 9 CSV Olist командами `\copy`
   (сами CSV в репозиторий не входят, см. `.gitignore`), выполнить `lab01/check.sql`.
3. Запускать `lab02/lab02.sql` и `lab03/lab03.sql`.

Подключение: host `localhost`, port `5433`, db `olist`, user `student`.

Работы 4–14 содержат README, проверенный SQL и фактические результаты. №10 выполняет повтор условия №9 из предоставленного файла. Для №12 используйте два сеанса по блокам; №13–14 содержат планы JSON.

В DBeaver lab04.sql–lab14.sql выполняются как SQL-скрипты, каждый в отдельном сеансе с загруженной схемой olist. Для №12 предусмотрены session_a_dbeaver.sql и session_b_dbeaver.sql; выполняйте их блоками в двух независимых соединениях с разными pg_backend_pid(). Исходные session_a.sql/session_b.sql предназначены для psql.
